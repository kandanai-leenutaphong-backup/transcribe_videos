สวัสดีครับ ก็วันนี้ก็จะต่อยอดจากตอนที่เราได้คุยกันเรื่อง Multi Agent นะครับ วันนี้เราจะเน้นไปทางหยิบ use case สักอันนึงมาแล้วก็ลองโค้ดมาตั้งแต่แรกจนจบแล้วเราลองมาดูกันนะครับ วันว่าวันนี้จะทำอะไร recap แบบไวๆนะครับ Multi Agent คืออะไรนะครับ Multi Agent เนี่ยก็คือเหมือนกับว่าเรา expand ออกจากการที่มี single agent เนาะ ถ้าใครยังไม่ได้ดูคลิปการทำ single agent หรือ concept Multi Agent ก็ไปดูได้ แต่มอติเอเจนท์เนี่ยก็คือเหมือนเรามีเอเจนท์ตัวใหญ่ตัวหนึ่งที่สามารถที่จะต่อเอเจนท์ตัวเล็กๆได้หลายตัวใช่ไหมครับยกตัวอย่างเช่นในรูปนี้ซุปเปอร์ไวเซอร์ก็คือจะเป็นเอเจนท์ใหญ่แล้วมันก็จะมีการต่อกับคอมเพนเซชั่นแล้วก็ดีฟเอเจนท์เดี๋ยวผมค่อยกลับมาอธิบายแล้วกันว่ามันคืออะไรแต่เบเนฟิตเลยอ่ะที่การที่เรามีมอติเอเจนท์เนี่ยมันมีอะไรบ้างก็คือว่าแต่ละเอเจนท์หรือแต่ละแอลเอ็มอ่ะครับที่เราใช้เป็นเอเจนท์เนี่ยมันสามารถรับโทเก้นได้จำกัดใช่ไหมครับ จากนั้นน่ะถ้าเราแยกเป็นแต่ละเอเจนต์คุยกันเนี่ยมันก็จะทำให้เราสามารถที่จะป้อนโทเก้นหรือว่าป้อนคำหรือ instruction เข้าสู่เอเจนต์ได้มากยิ่งขึ้น อันนี้เป็น benefit ของเอเจนต์อันหนึ่งนะครับ อีกอย่างหนึ่งเลยเนี่ยคือเรื่อง performance คือสมมติว่าเราให้หนึ่งแอลเอ็มเนี่ยทำ task หลายอย่างเกินไป สมมติแบบเราโยนให้เขาเลยประมาณสิบยี่สิบทูอะไรอย่างเงี้ย แล้วก็ป้อนไปเลยว่าทูเนี่ยทำอะไรบ้างใช่ไหมครับ แล้ววันหนึ่งเราสเกลไปร้อยถูกเงี้ยเอเจนตัวหนึ่งก็จะเริ่มลำบากและในการที่จะสามารถตอบได้มันก็เลยเป็นที่มาที่ไปว่าตัวมอติเอเจนเนลจะช่วยให้เราตอบได้ดียิ่งขึ้นถ้าสมมุติว่าเราแยกออกมาเป็นเอเจนเล็กๆที่เก่งแต่ละอย่างเหมือนอารมณ์เหมือนมนุษย์อ่ะครับเราพร้อมให้มนุษย์ทำลายอย่างเกินไปมันจะทำให้เราควบคุมผลลัพธ์ยากขึ้นเทียบกับว่าเราให้คนเก่งแต่ละอย่างใช่ไหมพร้อมแต่ละอย่างไปแล้วให้มันเก่งแต่ละดัด เนี่ยมันน่าจะดีกว่าแล้วก็สุดท้ายเนี่ยข้อดีอีกอันนึงก็คือว่าอีกเอเจนต์อีสอินดิเพนเดนแปลว่าอะไรแปลว่าสมมุติว่าเรามีเมนเอเจนต์อยู่ตัวนึงนะครับที่เกี่ยวกับเอชอาร์แล้วเราอ่ะอยากจะถอดตัวลีฟเอเจนต์ลงไปอ่ะเราให้มันมีคอมเพนเซชั่นเอเจนต์อยู่แล้วว่าวันหนึ่งเราเอาเอเจนต์ตัวอื่นมาพักอินแทนเนี่ยมันก็ทำได้อารมณ์เหมือนคล้ายๆการที่เราดีเวลลอปตัวไมโครเซอร์วิสในเว็บแอป เว็บ development นะครับเราสามารถที่จะแอดแต่ละดาราเซอร์วิสเข้ามาได้แล้วก็ถอดออกตามใจเราอันนี้ก็จะเหมือนกันเราสามารถที่จะแอดเอเจนต์เข้ามาแล้วก็ง่ายมากขึ้นนะครับโดยที่มันจะกระทบกับโคซิสเต็มน้อยลงอันนี้ก็คือจะเป็นข้อดีอีกอันหนึ่งของการทำเป็นมอลติเอเจนต์แต่โอเคเราทำเป็นเราดูข้อดีเสร็จแล้วเนี่ยเดี๋ยววันนี้เราจะมาใช้เจ้าตัวแรงกราฟนะครับในการ develop ตัวมอลติเอเจนต์แล้วก็ใช้ตัวกูเกิลเจมินาย ซีนาริโอของวันนี้คืออะไรก็คือจินตนาการนะครับคุณเป็นเอ็มพลอยที่กำลังจะเข้ามาในบริษัทใหม่แล้วบางทีคุณก็อาจจะไม่รู้ว่าคุณอยากจะรู้เรื่องคอมเพนเซชั่นหรือได้เงินเท่าไหร่อยากจะรู้ว่าลาอยากจะทำการลานะครับทำยังไงเราก็จะมีตัวเอเจนตัวหนึ่งนะตัวเล็กๆนะครับจริงๆตอนทำจริงเนี่ยมันจะใหญ่กว่านี้แต่ผมยกตัวอย่างให้เล็กๆแล้วกันว่าเอเจนตัวเนี้ยมันจะสามารถถามได้ในมุมคอมเพนเซชั่น มันสเตชั่นก็คืออะไรที่เกี่ยวกับเงินเดือนนะครับเขาเรียกเงินเดือนนู่นนี่นั่นแล้วก็เรื่องวันลานะครับเกี่ยวกับอยากจะดึงวันลาจากระบบแล้วก็อยากที่จะทำวันลาลงในระบบอันนี้อาจจะยังไม่ได้มีเรื่องของด็อกคูเมนต์เข้ามาเกี่ยวข้องนะครับอันนี้คือจะเป็นเรื่องถามเกี่ยวกับระบบที่ว่าวันลาเนี่ยมันมีเท่าไหร่ยกตัวอย่างเช่นองค์กรเราอาจจะใช้เวิร์คเดย์อะไรอย่างเงี้ยหรือว่าเอสเอพีในองค์กรอย่างเงี้ยเอเจนต์ก็จะช่วย คุยข้อมูลจากตรงนั้นได้เรามาดูกันว่าดีไซน์ยังไงก่อนที่จะลงโค้ดก็คือเริ่มแรกเนี่ยครับเราก็จะมีตัวซุปเปอร์ไวเซอร์เอเจนท์หรือว่าผมมองว่าเป็นเมนเอเจนท์นะครับตัวหนึ่งที่ผมจะเรียกชื่อว่าเมนเอชอาร์เอเจนท์เป็นเอชอาร์เอเจนท์ตัวเนี้ยมันสามหรือที่เป็นซุปเปอร์ไวเซอร์เนี่ยครับมันสามารถที่จะคุยได้ทั้งคอมเพนเซชั่นแล้วก็ลีฟเอเจนท์ยกตัวอย่างเช่นถ้าสมมุติผม ผมถามไปว่าผมอยากจะรู้ว่าผมมีวันละเท่าไหร่ในระบบสิ่งที่เกิดขึ้นก็คือว่าตัวซุปเปอร์ไวเซอร์เอเจนต์หรือเอเจนต์ตัวใหญ่เนี่ยมันก็จะทำหน้าที่เราไปสู่ตัวลีฟเอเจนต์นะครับแล้วก็ให้ลีฟเอเจนต์เนี่ยตอบให้เราแล้วก็คืนคำตอบออกมาซุปเปอร์ไวเซอร์เอเจนต์ก็จะรีเฟล็กว่าคำตอบโอเคหรือยังถ้าโอเคก็จบหรือถ้าสมมุติผมถามเกี่ยวกับเรื่องคอมเพนเซชั่นว่าเอ้ยผมมีเงินเดือนเท่าไหร่นะครับมันก็จะเราสู่คอมเพนเซชั่นเอเจนต์มันก็จะคืนกลับมาเช็คว่ามันตอบพอไหมนะครับ ทีนี้ถ้าจะทำอะไรที่ complex มากขึ้น ผมก็อาจจะถามว่าผมอยากรู้ว่าผมว่ามีเวลาเท่าไหร่มี compensation เท่าไหร่ในหนึ่งบรรทัดมันก็จะเราไปสู่ compensation agent คืนผลกลับมาแล้วก็เราไปสู่ leave agent นะครับ แล้วคืนผลกลับมาทำให้แบบมันเป็นการทำงานร่วมกันระหว่างหลาย agent นั่นก็คือจะเป็นตัวอย่างซึ่งในตัวอย่างวันเนี้ยก็จะมี tool ให้แต่ละ agent เนี่ยไม่มากนะครับ ก็เป็นตัวอย่างตัว leave agent เนี่ยเราก็จะได้อยู่สอง tool ก็คือการ submit leave นะครับว่า อยากจะทำวันลาแล้วก็อยากจะดูว่ามีวันลากี่วันในระบบเนี่ยเป็นทูสำหรับลีฟเอเจนต์ทำจริงน่าจะมีถูกมากกว่านี้เยอะแยะนะครับไม่ว่าจะเป็นทูในการช่วยค้นหาข้อมูลหรืออะไรอย่างเงี้ยที่เป็นเอกสารหรือว่าถูกอื่นๆที่เกี่ยวกับการทำวันลามันจะมีเยอะแยะอีกอย่างนึงก็คือตัวลีฟเอเจนต์ครับไอ้ตัวคอมเพนเซชั่นเอเจนต์ครับซึ่งตัวนี้มันมีอยู่สองทูด้วยกันก็คือเก็ทแซลเลอรี่แล้วก็เก็ทเขาเรียนโบนัสอ่าซึ่งสองทูเนี่ยก็คือจะ เป็นถูกที่เกี่ยวกับเรื่องเรื่องเงินเดือนเดี๋ยวเราไปดูกันดีกว่าโอเคอันนี้ก็คือจะเป็นตัวอย่างนะครับโค้ชที่จริงๆทำเหมือนแต่ก่อนที่เราเคยทำร่วมกันเลยครับก็คือเราสามารถที่จะอินสตอดีเพนเดนซี่ตามแรงกราฟรักเรื่องเช่นกูโค้ชเจในพวกนี้ได้เพื่อที่จะทำแบบนี้เราก็เข้ามานะครับในตัวโมติเอเจนท์นะครับทีนี้ผมรันไปแล้ว ผมอาจจะยอมลบตัวอย่างให้ง่ายๆลองเดโมให้ดูก่อนว่ามันเป็นประมาณไหนนะครับสมมุติผมถามไปว่าอยากจะรู้ว่าพนักงานเอ็มพลอยอีศูนย์ศูนย์หนึ่งเนี่ยมีวันลาเท่าไหร่สิ่งนี้เกิดขึ้นโอเคผมขออีกทีหนึ่งโอเคอยากจะเช็คว่ามีวันลาเท่าไหร่นะครับ สิ่งที่เกิดขึ้นก็คือตัวซุปเปอร์ไวเซอร์เอเจนต์เนี่ยก็จะเราสู่ตัวรีฟเอเจนต์เพื่อจะคืนว่าวันลาของคุณเนี่ยคือสิบห้าวันแล้วก็แปดเดย์มีสิกลีฟได้แปดเดย์นะแล้วถ้าผมเขียนว่าอยากที่จะซับมิวันลานะครับ vacation เนี่ยมันก็จะเราไปสู่ตัว vacation agent เหมือนเดิมในตัวรีฟเอเจนต์เหมือนเดิมว่าโอเคจะซับมิวันลานะครับประมาณนี้ถ้าผมถามเกี่ยวกับเรื่องเงินเดือนใช่ไหมอาจจะช่วยเขาเรียน แซลารีอะไรเงี้ยมันก็จะเร้าสู่ตัวคอมเพนเซชั่นเอเจนท์แล้วก็คืนผลกลับมาโอเคทีนี้โคต้าอันนี้ผมใช้ฟรีครับมันก็เลยจะขึ้นขึ้นจุดนี้แต่ว่าโอเคไม่ใช่ประเด็นครับประเด็นหลักก็คือว่ามันสามารถที่จะกระโดดไปสู่คอมเพนเซชั่นเอเจนท์แล้วก็คืนโบนัสให้เราได้ทีนี้ตัวอย่างหนึ่งก่อนที่จะไปดูลึกขึ้นนะครับยกตัวอย่างเช่นถ้าผมถามเกี่ยวกับเรื่องคอมเพนเซชั่น เอนเนอร์จีเนี่ยเราก็เรื่องรีฟเพอร์ฟอร์มแมนรีฟบาลานซ์นะครับเออในบรรทัดเดียวจะเกิดอะไรขึ้นสิ่งที่เกิดขึ้นก็คือว่าโอเคอย่างแรกเนี่ยมันก็จะทำการอ่านบรรทัดนี้ใช่ไหมครับมันก็จะวิเคราะห์ว่าโอเคเราจะไปเอเจนต์ตัวไหนดีทีนี้มันก็จะกระโดดไปนะครับสู่คอมเพนเซชั่นเอเจนต์แล้วก็คืนมาว่าโอเคตอนนี้คือเท่านี้นะครับทีนี้คอมเพนเซชั่นเอเจนต์เนี่ยมันไม่สามารถที่จะรู้เรื่องรีฟบาลานซ์ได้ใช่ไหมมันก็เลยกลับไปสู่ตัวซุปเปอร์ไวเซอร์เอเจนต์ที่จะหาตัวรีฟเอเจนต์อีกทีหนึ่งเพื่อที่จะ ดูว่าตัววาเคชั่นเนี่ยมันคือสิบห้าวันสิบเดย์เนี่ยคือเท่านู้นเท่านี้แล้วก็เราก็จะได้คำตอบเนี่ยก็คือจะเป็นการทำงานของมอลติเอเจนต์แบบไวๆเรามาลองได้ดูโค้ดกันไวๆครับคือคอนเซ็ปต์เหมือนเดิมคืออิมพอร์ตเจมส์นายครับเหมือนทุกวิดีโอที่เราทำแล้วก็อิมพอร์ตพวกแรงเชนไลบรี่ขึ้นมาเรามีถูกเกี่ยวกับเรื่องคอมเพนเซชั่นอยู่สองถูกอย่างที่ผมแปะไว้ในไอแพทนะครับสองถูกเกี่ยวกับคอมเพนเซชั่นเอเจนต์ แล้วก็สองถูกเกี่ยวกับรีฟเอเจนต์ก็จะเห็นได้ว่ามีแก๊สแซลลี่ที่เป็นบ็อกเรตต้าขึ้นมานะครับสำหรับเอ็นเจเนียร์เนเจอร์ไดเรกเตอร์แล้วก็จะมีเข้าโบนัสนะครับที่มีรับแซลลี่และเรตติ้งแล้วก็คืนว่าได้โบนัสเท่าไหร่เป็นบ็อกเรตต้าขึ้นมาเหมือนกันแล้วก็จะมีถูกที่เกี่ยวกับรีฟทูนะที่จะเช็คให้เช็คได้เลยว่าเอ็มพลอยที่ศูนย์ศูนย์หนึ่งและเอ็มพลอยที่ศูนย์สองเนี่ยมีวาเคชั่นเดย์เท่าไหร่แล้วก็การซับมิดลีฟเนี่ยก็คือจะเป็นสแตนดาร์ดซึ่งก็ต้องบอกนะว่าถ้าทำจริงๆเนี่ย คงไม่ได้ทำอย่างนี้หรอกนะครับตอนที่เขาอ่าทำนี้อาจจะต้องมีระบบล็อกอินอะไรอย่างเงี้ยในการออเทนติเคทว่าลิฟเดย์ใครลิฟเดย์มันแต่อันนี้ก็คืออยากจะให้แค่ดูคอนเซ็ปต์เฉยๆว่าคอนเซ็ปต์เนี่ยมันเป็นยังไงเอิมโอเคอันนี้ไม่มีอะไรครับเป็นรายละเอียดย่อยว่าเอ่อเป็นเคเปอร์ฟังก์ชันนะครับหรือเป็นฟังก์ชันที่ช่วยเหลือในการใช้ทูต่างๆจุดหลักที่ผมอยากจะให้สังเกตเนี่ยคือจะเป็นจุดนี้มากกว่าเอิมจะเป็นจุดตรงนี้ครับ ครีเอทรีแอคเอเจนต์รีแอคเนี่ยก็คือจะเป็นค่าชนิดหนึ่งที่เราจะใช้ทำสร้างเอไอเอเจนต์นะครับที่มันจะมีแบบติ๊กกิ้งพอเซสอะไรเงี้ยไอ้ตัวนี้มันก็คือจะเป็นคอมเพนเซชั่นเอเจนต์พูดง่ายๆเลยก็คือจะเป็นเอเจนต์ที่มีถูกเกี่ยวกับแซลลี่และโบนัสแล้วก็จะมีอินสตรักชั่นว่าเอเจนต์ตัวนี้ควรที่จะทำอะไรเนาะเราก็จะมีเอเจนต์อีกตัวนึงที่บอกรีฟเอเจนต์ที่ได้รับถูกสองถูกก็คือซับมิดลีฟแล้วก็เช็คบาลานซ์นะครับแล้วก็จะมี
